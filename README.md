## About

**Atrament** is a dark atmospheric browser platformer where ink is both your tool and your enemy.

You draw living ink to create platforms.  
The ink ages, bleeds, and eventually turns against you.  
Absorb it back before it becomes something worse.

Survive as long as you can.  
Reach higher Depths.  
Advance through Chapters.

---

## Features

- Draw living ink platforms in real time
- Ink ages and can transform into hostile creatures
- Absorb system to reclaim ink and clear danger
- Depth & Chapter progression system
- High score saving (Best Depth)
- Full mobile support (virtual joystick + touch controls)
- Desktop keyboard controls
- Atmospheric sound effects & screen shake
- Dark parchment visual style

---

## How to Play

### Desktop
| Action | Control |
|--------|---------|
| Move | `A` / `D` or Arrow Keys |
| Jump | `W` / `Space` / Up Arrow |
| Draw Ink | Click + Drag |
| Absorb | `E` |

### Mobile
| Action | Control |
|--------|---------|
| Move | Virtual Joystick (left) |
| Jump | JUMP button |
| Draw Ink | Touch + Drag on screen |
| Absorb | ABSORB button |
